# production_line
System Overview

This project presents a simulation system designed to emulate a realistic electronics workbench environment for soldering tasks. The simulation includes a virtual work surface, tools, and environmental conditions that mimic real-world soldering scenarios.
A key feature of the system is its integrated ionizing fan module, enabling dynamic control over the electrical charge present on the work surface. By adjusting ionization levels, users can observe and analyze how electrostatic conditions influence soldering processes, component handling, and overall workstation safety.
The system provides an interactive training and testing environment, supporting scenarios such as:

Monitoring and manipulating surface charge levels
Understanding the impact of electrostatic discharge (ESD) on components.

Practicing safe soldering workflows under varying electrical conditions.

Experimenting with environmental factors in a controlled, risk‑free setting.

Unity Hub Requirement
This project is developed as a Unity‑based simulation and must be opened, managed, and launched through Unity Hub.
To get started, import or add the project folder inside Unity Hub and open it with the Unity version specified in the project settings.
